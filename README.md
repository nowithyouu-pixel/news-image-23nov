A pure-stdlib Python program that draws the world news of Monday 23 November 2026 as a one-page newspaper front page — masthead, lead story on Iran's strikes on US bases in Bahrain, and six more stories from Kyiv, Antalya, Finland, Seoul, New Delhi and Indonesia — and writes it to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The run is deterministic (same bytes every time), uses no network and no third-party packages, and finishes in under a second.
